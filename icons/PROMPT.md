# "Saturn" glyph icons for the Windows Start menu

One consistent set of 13 app icons. The Start menu shows each icon inside a dark teal rounded tile,
so the icon itself is ONLY the glyph on a fully transparent background (no tile, no square, no frame).

## Style (identical for every icon)
- Pixel art glyph, like a 32x32 pixel sprite scaled up cleanly (hard square pixels, no blur, no antialiasing).
- Matches a pixel-art night wallpaper: a ringed planet in eclipse over dark teal sky and amber horizon.
- Palette ONLY: gold #E3B05C (main), light gold #F2C96B, cream #F1E6C4 (highlights), amber #A56921 (shadow),
  plus at most a tiny touch of teal #5FB3A0. Never white, never black fill.
- A simple, bold, readable SYMBOL of the app (a simplified hint, not an exact brand logo), centered,
  filling about 70% of the canvas, readable at 32x32 px.
- Optional tiny sparkle pixels (like the stars on the wallpaper), max 2.
- No text, no letters, no watermarks, no background.

## Format
- PNG 1024x1024, fully transparent background.
